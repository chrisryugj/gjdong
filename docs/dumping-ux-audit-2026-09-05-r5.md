# /dumping UX 감사 5라운드 (2026-09-05)

두 독자(공모전 평가자, 광진구 정책 결재선)가 각자 5분 안에 판단을 끝낼 수 있는지, 컨텍스트 없는 서브에이전트 둘에게 프로덕션 캡처(1440·1024·390, 탭 5개·모달 5종·브리핑 PDF)와 화면 글자만 주고 읽혔다(`shower` 방식). 고치기 전 냉독이 1절, 고친 뒤 로컬 캡처로 같은 질문을 다시 읽힌 결과가 3절이다. 캡처 원본은 스크래치패드에 있고 이 문서가 인용하는 것만 `dumping-ux-audit/` 폴더에 있다.

질문은 둘뿐이었다.
- 평가자: 이 분석이 무엇을 밝혔고, 근거가 어디 있고, 다른 구에서 재현 가능한가를 5분 안에 알 수 있나. 첫 화면에서 데이터 출처, 방법, 결론, 한계로 가는 길이 보이나.
- 결재선: 무엇을 결정해 달라는 건지, 돈이 얼마 드는지, 누가 하는지, 안 하면 어떻게 되는지를 한 장에서 읽을 수 있나. 통계 용어 없이 이해되나. 인쇄해서 결재판에 끼울 수 있나.

### 3.2 냉독 뒤 추가로 고친 것 (재촬영으로 확인, [r5-after-1440-policy-print.png](dumping-ux-audit/r5-after-1440-policy-print.png))

- 결재용 한 장 맨 위에 결재란(담당·과장·국장·부구청장·구청장 빈 칸), 요청 문장 문두 "아래 6건의 검토와 시행을 요청합니다", 수치 박스를 표 아래로, 머리에 민원·과태료 기간 병기, 하단에 기안자·기안일·문서번호 빈칸 표기
