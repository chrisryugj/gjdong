## 1. 결재 문서화(냉독 4절 "그래서 뭘 하면 되나" · 가장 큰 감점)

점검 후보 5(`lib/snow/facts.ts buildChecklist`)가 사실 나열에서 멈춘다. 담당·기한·규모를 붙이되 **데이터에 있는 것만**, 없는 건 "내부 확인" 슬롯으로 비워 둔다(지어내지 않는다).
1. `CheckItem`에 `dept`(소관 부서: 그래프 Team 노드에서. 적설취약구간·제설함·열선 = 도로과 도로관리팀, 염화칼슘함·모래주머니·동 단위 = 동주민센터, 시 관리 = 관리청명 그대로, 학교 = 교육지원청은 데이터 없음 → "내부 확인"), `due`(대책기간 시작 `ops.period.from` 2025-11-14 기준 "대책기간 전"), `scale`(수량: 자재 n개소·열선 n구간 m·학교 n교), `action`(행동 동사 하나: 비치·검토·확인 요청·점검. 후보 4·5는 지금 사실문이라 동사가 없다).
2. 공백 탭 02 행을 "동사 제목 · 부서 · 기한 · 규모" 한 줄 + 근거 한 줄로. 비용은 데이터에 없으므로 쓰지 않는다(냉독이 요구했지만 출처 없음. 모달 "못 구한 데이터"에 "자재·열선 단가" 추가).
3. 시 소관 6곳은 "관리청에 확인 요청" 항목에 관리청별 구간 수(시설공단 2·동부도로사업소 4)를 붙인다.
4. "조치 여부와 순서는 담당 부서가 정합니다"가 두 곳(01b·장면 5)에서 반복 → 한 곳(02 부제)만.
5. 후보 순서: 구 소관 행동 가능 › 시 요청 › 동 단위 › 학교. 100m 경계(108m) 사례는 본문에 "기준 100m는 가정" 유지.

**게이트 1**: 후보 5행 전부 동사 제목 + 부서(또는 "내부 확인") + 기한. `tests/snow-copy.test.ts`에 후보 `title`이 동사로 끝나는지(비치·검토·요청·점검) 단언 추가.

## 2. 지도 기호 자기설명(냉독 #4·#7·#18·#21)

1. **번호 체계 하나**: 지도 위 번호는 이제 표와 같다(적설취약 i·결빙 n). 동별 기둥 1~3위 입체 숫자는 기둥 모드에서만 뜨지만 냉독 3회 모두 "게임 UI"로 읽음 → 기둥 꼭대기 숫자 대신 `colLabel` 두 줄 라벨에 "1위" 접두(`dongColsFC label`)로 옮기고 `dongRank` 3D 숫자는 시연 장면 2에서만 켠다(사용자가 dumping 규격으로 요구한 것이라 삭제 말고 시연 전용).
2. **열선 있는 취약구간 34곳**: 회색으로 바꿨으나(a3b732d) 확대에서 여전히 "빨강 두 톤"으로 읽히는지 z15 스크린샷으로 확인. 안 되면 열선 있는 구간은 `line-dasharray [2,2]` 회색 점선.
3. **초등학교 깃발**: 노랑 = 열선 있음(6), 흰 = 없음(15)로 바꿨다. 범례 문구와 조망 스크린샷 대조.
4. **결빙 1·2 선형 미확인**: 강 건너 끝점은 이제 안 찍는다. 남은 끝점 2개가 자양4동 서쪽 끝에서 라벨과 겹치는지 확인, 겹치면 라벨 `text-offset` 아래로.
5. **평면 기본 여부**(냉독 #21 "평면이 더 읽힌다") → 사용자 결정 사항. 추천안: 입체 기본 유지하되 **모바일(390)은 평면 기본**(3D 핀이 작은 화면에서 점으로 뭉개짐). 확답 뒤 `DEFAULT_VIEW.tilt`를 `isMd`로.
6. 범례 "취약구간 · 진하면 열선 없음" → "취약구간 진홍 = 열선 없음 · 회색 = 열선 있음".

**게이트 2**: 조망(z13.2)·동네(z15.5) 입체 스크린샷에서 범례에 없는 기호 0, 번호 체계 1개.

## 3. 대응 단계·법령 탭 지도 연동(냉독 #5·#10·#13)

1. 대응 단계 탭 진입 시 지도가 단계 상태를 보여야 한다. 지금은 평시(시나리오 5cm = 2단계)라 제설함 2.2배만. 탭 진입 시 `layers`를 단계 동원 목록(`MOBILIZED[stage]`)으로 맞추고, 2단계에서 제설함 3D 핀에 `setBoost` 외에 발광(emissive 0.6)을 준다. 시연 장면 3 자막 "제설함 110개소를 확대 표시합니다" 시점에 실제로 커지는지 스크린샷 2장(격상 전·후 픽셀 diff > 2%).
2. 자원 표에서 건축물관리자·민관협력은 "구 보유 자원"이 아니다 → 표를 "구 보유 7종(지도 4·보도자료 3)"과 "외부 의무·협력 2종"으로 나눈다(그래프 Lever 노드에 `kind: own|external` 속성 추가, `scripts/snow-data.mjs buildGraph`).
3. 법령 탭: 지도가 놀고 있다. 조례 4조 범위(대지경계 1m)를 표본 블록 하나로 그리지 말고(데이터 없음) **관리청별 색**으로: 탭 진입 시 취약구간을 소관 구/시 두 색으로 칠하는 `ownerView` 모드(`weakFC`·`iceFC`에 `owner` 속성은 있음). 범례 문구 동기.

**게이트 3**: 단계 탭 격상 전후 diff, 법령 탭 스크린샷에 구/시 두 색.
