# /dumping 5라운드 계획 (2026-09-05, 냉독 뒤 확정)

목표: 공모전 평가자와 정책 결재선이 각자 5분 안에 판단을 끝낼 수 있는 화면. 숫자·모형은 손대지 않는다.

## 냉독 결과 요약 (docs/dumping-ux-audit-2026-09-05-r5.md)
- 평가자: "일부 가능". 재현 경로가 첫 화면에 없음, 논리 충돌(사람 아니다 vs 사람 겨냥), 계수 여러 개·"13개 조건" 출처 불명, 변수 이름 셋
- 결재선: "불가능". 결정 요청 문장·금액·안 하면 없음, 결재용 한 장 없음, 첫 화면 큰 숫자 셋이 통계 기호
- 인계 8건 중 냉독이 다시 찾은 것: 1(헤더·온톨로지) 2(발견 순서는 아님, 카드 뒤 배치) 3(변수명) 4(주소 미상) 6(담당·검증 표) 7(재현 경로) 8(390). 5(시드 펼침·말투)는 못 찾음

## 작업 순서
1. 구조: 헤더(과태료 기간 표기·그래프 규모 이동), 탭 "근거 그래프", 정책 탭 = 결론+쉬운 수치 3+평가자 링크 줄+제안 표+결재용 인쇄(`#dump-policy`), 발견 탭 카드 먼저·대비 보드 접힘·카드 순서, 브리핑 주소 없음 행, 390 패널 먼저(use-split-pane에 mapBelow 옵션 1개)
2. 변수명 통일 "다가구·단독 밀집" (정의 문장은 방법 모달·지도 도움말 두 곳)
3. 카피: 줄표 0, 결측 "미산출", 금지 문구 0, 챗봇 말투 0, 시드 `qa-seeds.ts` 분리·기본 펼침 1
4. 비공개 export: COV_KO·LABEL_KO·ev-ledger 요약·문자열 치환 sanitizer(줄표·옛 변수명, 의무관리 보호)
5. 재수출(manifest → export → verify → encrypt) → 게이트 grep → 테스트·lint·tsc·build → 로컬 3해상도 재촬영·PDF 픽셀 검사·QA 평가셋 → 냉독 2회차 → 푸시 1회 → 프로덕션 재확인 → 검토서 9절·인계

## 결정한 것 (사용자에게 묻지 않고)
- 변수명 gate는 `grep "무관리\|관리주체 없는" | grep -v 의무관리`. "의무관리"는 공동주택관리법 용어라 바꾸지 않는다
- 줄표 gate의 `tests`는 dumping·onto 테스트만. crowd 테스트 주석 줄표는 이 요청 밖
- 시드 기본 펼침은 1(답 형식 예시 하나만)
- 결재용 한 장의 "안 하면"과 예산 금액은 자료에 없어 비워 둔다(사용자 결정 사항으로 보고)
